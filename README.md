# Baya, redirection

Ce dépôt ne contient plus le projet. Il ne sert qu'à maintenir en vie
l'adresse `https://turibiok.github.io/Baya/`, citée dans les dossiers BWAI
2026, doctorat, matériel et projet déjà transmis.

Le projet est désormais ici :

- Site : https://g-one-health-innov.github.io/Baya/
- Dépôt : https://github.com/G-one-health-innov/Baya

GitHub redirige les adresses de dépôt après un transfert, mais pas les
adresses GitHub Pages. Sans ce dépôt, tous les liens imprimés dans les
documents déjà envoyés seraient morts.

La page `index.html` conserve le chemin demandé : un lien profond vers
`turibiok.github.io/Baya/une/page` arrive sur
`g-one-health-innov.github.io/Baya/une/page`, et non sur l'accueil.

Ne pas supprimer ce dépôt tant que des dossiers portant l'ancienne adresse
circulent.
